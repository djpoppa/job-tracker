# Job Tracker

A modern web application built with React to help organize and manage job applications throughout the job search process.

This project was created to strengthen my React skills while building a practical application that I can use and continue expanding over time.

## Live Demo

*(Coming Soon.)*

## Features

### Current

* Create, edit, and delete job applications
* Track application status
* Store data locally using browser Local Storage
* Responsive card-based interface
* Light and dark mode
* React Router navigation

### Planned

* Search applications
* Filter by status
* Sort applications
* Dashboard statistics
* Resume analysis tools
* ATS keyword checker
* Cover letter generator

## Built With

* React
* JavaScript (ES6+)
* Vite
* React Router
* CSS3
* Local Storage API

## Running Locally

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/job-tracker.git
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```
